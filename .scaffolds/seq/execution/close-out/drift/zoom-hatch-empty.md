# Drift: the zoom hatch over a track that draws nothing

**Where**: region reads (the hatch), CL3 item 5 (answer G12). **Found by**: CL3, 2026-11-24.

**The designs say**: answer G12: "a track that draws nothing at this zoom gets the same hatch, never an empty band".
`region-reads.md`'s earlier decision: where a region has no items, "no arc, no placeholder".

**The conflict**: a hatch saying "zoom in to read" over a region that simply has no data says something false.

**Decided overnight, as recommended** (the loop, Running while the author is away; in `gaps.md`): the hatch is drawn
where data exists but this level does not draw it (the source's level is too coarse or the items too many); where the
region has no items, the track follows the empty-well rule (a one-line row naming it, "no items"), never the hatch and
never a blank band. Both designs hold: G12 for the first case, "no placeholder" read as "no zoom placeholder" for the
second. To the next fix lane.
