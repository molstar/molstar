# seq

`packages/seq` is a new implementation of Seq\*: SeqViewSpec, a JSON language for sequence views over one coordinate
model, with its model, query language and viewer, in the Mol\* v6 repository.

It is an instance of the principles package: the package is `.scaffolds/principles/` (copied from the upstream exploration repository at
`7d03f60`, 2026-11-17); this project's own modules, designs, sources, records and work folders are in `.scaffolds/seq/`.

1. **Read the manifest**, `.scaffolds/seq/principles/README.md`: the folder map, the modules and the adaptations.
2. **Read `principles`** (`.scaffolds/principles/_skills/principles/SKILL.md`, how work is run), then **`principles-router`**
   (`.scaffolds/principles/_skills/principles-router/SKILL.md`), which picks modules from that manifest.
3. Before you start:
   - `.scaffolds/seq/` is kept, never cited: code and specs never cite it; `packages/sequences` (the previous implementation) is a source
     to read, never named in `packages/seq`.
   - The checks are in `.scaffolds/seq/AGENTS.md` (Checks); the repository's are in the root `AGENTS.md` (Commands).
   - The author is David Sehnal; decisions on principles, sources and designs are his.
