# adopt-principles: the independent review and the reconciliation (2026-11-17)

## Asked

- Commit the current spec and run an independent review with Fable 5.2 as advisor; then act on it: "one" version; the
  tree core "codec indepedent and about abstract patterns"; "this is not just about scope, but about reconciling the
  architecture, fixing things from the "reply", etc"; "rest as recommended".

## Decided

- One language, one version, four levels (`data`, `views`, `refs`, `snapshots`): [design/composition.md](../../design/composition.md).
- `@molstar/core/repr` codec-independent; JSON and S-expression codecs in core, MessagePack in io:
  [design/tree-core.md](../../design/tree-core.md).
- As recommended: JSON by default, MessagePack for large inline data; typed columns declared, hashed by bytes, printed
  elided; large data in sources ([design/format.md](../../design/format.md)). Three compiled forms and a data store
  ([design/data-store.md](../../design/data-store.md)). Ports cut to assets, text metrics, structure; the host is
  `DomHost`; archives over the assets port ([design/ports.md](../../design/ports.md)). One typed configuration;
  settings layers, the form, def/use, public layouts and chrome parts deferred. Addresses with strings, lists and URL
  encoding; data-made elements by forms; viewport a command's argument. Test budgets per folder and in total; few
  records; no parity test. Performance numbers measured on the first slice. The Genomes dataset a later milestone.
  `_spec` holds only what is built. oz's `workspace` and `layout` removed.
- The order of work: the review's first slice ([design/version-1.md](../../design/version-1.md)).

## Delivered

- A long design conversation drifts: the same statement in designs, `_spec` and docs pages diverged within hours. The

- Questions asked in passing were recorded as decisions; a record should mark a question as a question until answered.
