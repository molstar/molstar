# Bootstrap {#bootstrap}

The entry point for an agent asked to adopt these principles in a project. Point a fresh agent here.

1. **Read** [_core/recurrence.md](_core/recurrence.md) (the loop all work is a step of), the "In brief" of
   [_core/workflow.md](_core/workflow.md) (how work is run), "The manifest" and "Code patterns" in
   [_core/system.md](_core/system.md), and the module list in [README.md](README.md#modules-the-catalogue).
2. **Run the procedure** in [_core/patterns/adopting.md](_core/patterns/adopting.md), in order: ask the author
   first, create the instance, copy and map, coexist with the host, link the skills, wire the checks, set up the first work folder and lane
   briefs, and fold back. Each step says what to verify.
3. **Stop and ask** wherever the procedure says to; don't guess the scope, the authors or which rules the host keeps.
4. **Finish** when its "Done when" list holds, and leave a session record of the setup (work id `adopt-principles`)
   ([workflow-files](_core/patterns/workflow-files.md#session-record-recordswork-iddate-namemd)).

Once the package is in place, later sessions start from the `principles` skill, not from here.
