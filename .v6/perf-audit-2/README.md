# Performance audit v2: index

Goal: second run of the [v1 audit](../perf-audit/README.md) (2026-10-19, base `60fe4c2f1`) after the ~30 perf and
bug-fix PRs since (`git log 60fe4c2f1..0944823d4`). Re-classify every v1 finding (fixed / partly fixed / still open /
regressed / dropped), find the big wins that remain or are new (algorithmic complexity, per-element allocation,
recompute that could be cached or incremental, oversized buffers, blocking main-thread work), and record every real bug
met along the way. Read-only: nothing under `packages/` was changed. HEAD `0944823d4` (= master), 2026-10-22, Node
25.6, Apple M4, headless, shared machine at load 2–5 (times ±10–20 %; allocated and retained MB reproduce).

Constraints: Canvas3D and `packages/graphics/src/gl` are frozen while WebGPU lands (findings there are recorded with
`frozen`); MVS loading and animation are in [mvs-optimizations](../mvs-optimizations/research/README.md) and not
repeated. Bugs are listed in [bugs.md](bugs.md). Ids are slice-qualified (`05/P13`); a v1 finding keeps its v1 id, new
ones continue after the slice's highest v1 id.

## Method

1. **Profile** ([00-profile.md](00-profile.md)): the repo's pipeline bench (`scripts/pipeline-bench.mjs`) as an
   **A/B in one session**: the v1 base `60fe4c2f1` (`git archive` into the scratchpad, same `bench.ts`) against HEAD,
   on 7qpd, 3k7f, 8zzh, 1tup-2x2x2, flat-32 (= v1 `big-bcif`), asm/flat-192, asm/flat-864, 500 small structures and
   playback. Time, allocation, retention, render buffers, CPU and allocation profiles, `--trace-deopt`.
2. **Per-slice audit**: one auditor per slice first re-classifies each v1 finding against the code and a rerun of its
   bench, then hunts new findings (P = perf, B/N = bug, H = app-level hypothesis) with a bench or probe per claim.
3. **Adversarial verify**: a second pass re-reads each finding with its callers and re-runs the benches. Refuted
   findings are removed; estimates and verdicts are the verifier's (e.g. 01/P5, 07/P20 → P16, 08/B9 refuted, 09/P17
   and 12/P1 lowered, 05/B14 widened, 13/P4 corrected from fixed to partly fixed).
