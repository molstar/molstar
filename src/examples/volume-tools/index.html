Volume Tools

Interactive volume tools built on Mol*. Open a local .mrc/.map file inside either tool.

Volume Mask Creator

Draw polygons from any camera angle to carve a single soft-edged mask out of a volume, optionally combined with atomic structure proximity, and export it as MRC.

Volume Segmentor

Split a volume into several bodies by drawing polygons from several views, keep the remainder as its own body, remove dust, preview soft masks and export one MRC mask per body.
