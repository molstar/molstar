# Mol* v6

Mol* v6 modernizes the library's package structure, distribution, and plugin
composition so applications can use the parts they need with clearer dependencies
and less setup.

## Goals

- **Modular packages:** separate core utilities, IO, molecular models, graphics,
  plugin runtime, UI, headless support, and MolViewSpec into packages with explicit
  ownership and dependencies. Extensions, apps, examples, CLIs, servers, and
  browser distributions have their own workspace locations. Public packages
  share one release version.
- **Direct ESM consumption:** publish JavaScript modules and TypeScript declarations
  for Node and browser consumers, including a browser-ready distribution that can
  be used without a consumer build step. Keep source entry points for bundlers.
- **Explicit plugin composition:** let applications choose formats, representations,
  themes, transforms, and behaviors through deliberate feature registration.
  Provide full default configurations through explicit entry points and make
  smaller application bundles practical.
- **A rendering-backend boundary:** separate GPU resources, scenes, passes, and
  readback from the rest of the library while retaining WebGL behavior. This
  prepares a path to WebGPU and offline rendering; complete WebGPU and Blender
  implementations are later work.
- **Simpler development and reliable releases:** use shared workspace tooling,
  app-owned builds, and consumer smoke checks for published artifacts. Use Biome
  for linting and formatting, native TypeScript 7 for compilation, and track API
  changes and migration work explicitly.

## Current progress

The current implementation establishes the pnpm workspace, package layout, ESM
exports, app tooling, browser distribution, and Biome linting with optional
formatting. Compilation uses native TypeScript 7; repository-wide formatting is
next. Plugin composition and rendering backend work remain planned. The structural
prototype is an initial step toward v6, with remaining architecture, compatibility,
and release work tracked below.
