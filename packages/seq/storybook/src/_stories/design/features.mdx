# Features

What this version will contain. Nothing is built yet; each feature will link its view here once it runs.

## Planned

- **Language**:
  - a spec written with a typed builder, stored as JSON (or MessagePack for large inline data), printed as
    S-expressions;
  - validation that reports every issue;
  - versions and migrations;
- **Coordinates and maps**:
  - indices and labels; numbering schemes (Kabat, IMGT);
  - cyclic systems;
  - map kinds: identity, offset, numbering, segments, pairwise, alignment, codon, structure;
  - maps written inline, read from a source, or computed by a runtime, and held compressed;
  - direction on every run; paths and projection; codon tables;
  - structure maps (SIFTS in abstract form);
  - pieces, reversed blocks and collapsed introns.
- **Data and sources**:
  - sequences, units, copies and ligands;
  - alignments and trees;
  - the six annotation shapes;

  - the text formats: FASTA, alignments, tables, Newick.

- **Streaming and patches**: how state changes. Patches edit the spec and are the only undoable changes; streams bring
  data and are never undone or saved.
  - patches by address, all or nothing, with inverses and a correct `diff`; undo and redo, one step a batch;
  - previews: a gesture's transient change, ending in one patch or a cancel;
  - snapshots: named patches over the base (leaving a step is navigation, not undo);
  - patches on streamed things (a bookmark on a transcript that comes and goes), and a command to keep a region on
    purpose;
  - patch streams from an agent or a host, applied in order (collaboration later);
  - every command says whether it edits the spec, changes the session or only navigates;
  - self-describing sources: format, location, index, assembly, aliases, fields;
  - one source protocol for inline and streamed data: what a source covers, and a region at a level of detail;
  - answers that carry nodes as well as tables (transcripts, nested sources, their own coordinate systems), shown by
    track templates;
  - a data store with versioned entries, pending never drawn as empty, prefetch, cancellation and byte-bounded eviction;
  - open value domains computed when the view settles; exports that wait for their data;
  - format runtimes as registry entries, bigWig as the proof, a synthetic asynchronous source for tests.
- **Layers and themes**:
  - letters, ranges, values (with points, split and log scale), variants, pairs, matrix, grids and dot plots, logo,
    secondary structure, ruler, frames, rows;
  - fallbacks;
  - themes, residue schemes, shared domains, legends, size channels.
- **Views**:
  - tracks and text layouts, alignment figures;
  - blocks, rings, navigators;
  - follow and scroll groups, merged copies.
- **Interaction and editing**:
  - a configurable gesture grammar;
  - hover across linked sections, selection, the keyboard cursor;
  - focus and reveal, highlights;
  - search and queries;
  - track and group editing;
  - the hover card and context menu.
- **Rendering**:
  - the resolved view and draw lists as public forms;
  - Canvas2D, SVG and PNG, the same picture;
  - a render CLI, a text-metrics port;
  - the UX foundations.
- **Ports with default adapters**: assets (Mol\*'s asset manager), text metrics, structure; archives over the assets
  port.
- **Configuration and extensions**:
  - one typed configuration (settings in layers and a generated form come later);
  - layout and spacing in presets;
  - extension descriptors;
  - node kinds and custom fields;
  - every registry open.
- **Addressing**: local, hierarchical ids; addresses as `path/(query :key value)` for nodes, locations, elements and
  rects; user-defined refs (bookmarks are refs); commands and markdown links act on addresses; copy link. Built: refs
  and bookmarks (on dynamic nodes too), addresses resolved and printed back, links, the commands, the selection and the
  focus as addresses (the Features › Addressing stories); highlights are not drawn yet.
- **Integration and showcases**:
  - a Nightingale reference rendering of a subset;
  - bigWig read by region, as proof that a genome format plugs in;
  - an application composing services (UniProt, PDBe, AlphaFold DB) and reading structure files;
  - the Mol\* link: a lab's position-indexed predictions mapped onto a structure's `label` and `auth` numbering.

## Deferred

Each is deferred until the trigger named for it.

- **A published JSON Schema**: until an outside reader or an agent tool needs one.
- **The Genomes milestone**: layers across sections and synteny, contact maps, a MAF over a genome, values for genomics
  (points, split, log scale), variants by sample, matrices, keyed joins, gene hierarchies, and the genome formats beyond
  bigWig: after version 1's views run.
- **Writers (FASTA, PDF)**: until the first writer extension.
- **Agent tools**: until the language description and addressing are built.
- **A React adapter**: until a React host asks.
