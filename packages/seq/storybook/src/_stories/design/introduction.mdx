# Seq\* (next)

Seq\* is **SeqViewSpec**, a language for sequence views, and a viewer for it. A **spec** is a tree, stored as
MessagePack or JSON, that says what data there is and how to show it. Every position lives in a **coordinate system**,
and **maps** connect systems:

- a protein onto its gene's codons, across introns;
- an alignment's rows onto its columns;
- a design onto its wild type;
- a chain onto its structure;
- one genome onto another, inversions included.

Data placed on one system shows on every system it maps to, and hover, selection and focus follow it there.

This is a new implementation, under way. These pages say how it will work; the examples come to life as the pieces are
built.

## Three readers

- **People**, writing specs by hand or with a typed builder, and reading them printed as compact S-expressions.
- **Agents**, writing and patching specs: the language is small, its docs and skill are generated from its own
  description, and validation reports every issue with a stable code and a hint.
- **Other viewers**: the JSON is documented by the language reference, the resolved view is public, and data comes
  through one protocol, so a reader needs no Seq\* code to open a spec.

## The packages

| Package                | What                                                                                                        |
| ---------------------- | ----------------------------------------------------------------------------------------------------------- |
| `@molstar/seqx-core`   | the language, the coordinate model, the source protocol, queries, and the pure passes from spec to pictures |
| `@molstar/seqx-viewer` | DOM-free models on `@molstar/core/reactive`, Canvas2D and SVG backends, the default UI on `@molstar/ui`     |

`seqx` is a working name; the packages become `@molstar/seq-*` when they replace the current ones.
