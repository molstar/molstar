# Bundled fonts

Liberation Sans and Liberation Mono, regular and bold, version 2.1.5, unmodified, under the SIL Open Font License 1.1
([OFL.txt](OFL.txt)). They are the only fonts the PNG rasterizer loads.

- **Upstream**: Liberation Fonts 2.1.5, <https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5> (the
  `liberation-fonts-ttf-2.1.5` archive).
- **Source of these copies**: the `fonts/truetype` folder of a LibreOffice runtime that ships Liberation 2.1.5 (the
  files' own version string says `Version 2.1.5`), not the upstream archive. **They were not checked against the
  upstream release** (no download was made); compare the hashes below with the archive's files before relying on them as
  upstream's.
